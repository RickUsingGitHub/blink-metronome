    Install

    Add Blink to your home screen and it runs full screen and offline. On iPhone: Share → Add to Home Screen. On Android: the menu → Install app.

    Shortcuts

    Tap the tempo dial to type a number; turn it to nudge. Space starts and stops. ↑ ↓ change tempo by one, ⇧↑ ⇧↓ by ten. T taps. 1–9 set the beats in a bar. S toggles sound.
